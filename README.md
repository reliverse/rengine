# Rengine

Rengine is an open-source 2D and 3D game engine for building games, interactive tools, and content creation workflows.

It is powered by `rese` framework and developed within the [Reliverse](https://github.com/reliverse) and [Bleverse](https://github.com/reliverse/bleverse) ecosystems.

## Project Structure

For now, the future `reliverse/rese` repository structure is developed inside `reliverse/rengine`.

This is intentional: `rese` is being matured inside a demanding real-world engine project before being extracted into a standalone repository.

After Rengine reaches a more stable stage, `rese` will move into its own repository.

See [rese/README.md](rese/README.md) for more information.
